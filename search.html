RELATED WORD SEARCH

Semantic search gets the context behind the query. It goes beyond keywords to find related terms and concepts.

For example, a search for “car” may include results for “vehicle registration,” “insurance,” and “driver’s license,” reflecting the user’s need for all items associated with the concept of a car. This approach ensures a more comprehensive and intuitive search experience, where users find relevant information that aligns with their overall goal.

DEEP CONTENT SEARCH

Semantic search understands user intent, not just keywords, allowing for more relevant document retrieval. For example, searching for “white dress” can yield results like “wedding dress” or “wedding planning.”

It also identifies relevant content within a single file, scanning across slides or pages. This makes it easy for users to find all the information they need without opening each file individually.
